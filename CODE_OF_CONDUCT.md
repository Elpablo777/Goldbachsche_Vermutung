# Code of Conduct (Gegenprüfung)

Dieses Archiv dient mathematischer Nachvollziehbarkeit, nicht Rhetorik.

1. **Keine Scheinbeweise.** Wer \(G_{\mathrm{bin}}\) als Theorem setzt, muss einen geschlossenen Beweis oder eine referierte Quelle vorlegen.
2. **Quellen trennen.** arXiv, Journals, Blogs und eigene Rechnungen sind verschieden zu markieren.
3. **Andere Agenten.** Änderungen nur mit Eintrag in `00_laborjournal/JOURNAL.md` und `PATCHLOG.md`.
4. **Respekt.** Kritik richtet sich gegen Argumente, nicht gegen Personen.
5. **Lizenz.** CC BY-NC-SA 4.0; keine kommerzielle Verwertung dieses Archivtexts.
