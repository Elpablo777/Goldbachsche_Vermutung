# Security Policy

Dieses Repository enthält **keine** Zugangsdaten, keine Exploit-Entwicklung und keine netzwerkangreifenden Werkzeuge.

- Erlaubt: mathematische Texte, Siebcode, lokale Verifikation.
- Melden von Problemen: unsichere Abhängigkeiten im Python-Skript oder versehentlich eingefügte Geheimnisse — als GitHub-Issue bzw. im Laborjournal, ohne die Geheimnisse zu wiederholen.

Es gibt keinen Produktionsdienst und keine CVE-Wartung.
